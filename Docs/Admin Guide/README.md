# EgbeAnom Admin Guide

This is the plain-English guide for running the store.

It is written for someone who does not code.

## Start Here

1. Read [Overview](./Overview.md).
2. Check [Store Info](./Store%20Info.md).
3. Check [Taxes](./Taxes.md).
4. Check [Shipping](./Shipping.md).
5. Check [Email](./Email.md).
6. Use [Orders](./Orders.md) every day.

## Important Rule

Do not ship an order unless its financial status says paid.

## Pages

- [Overview](./Overview.md) - Use this page first. It shows the biggest numbers and points you to the work that needs attention.
- [Catalog](./Catalog.md) - Use this to add, edit, and check products.
- [Categories](./Categories.md) - Use this to group products so shoppers can find them.
- [Inventory](./Inventory.md) - Use this to watch stock counts and print a simple stock table.
- [Carts](./Carts.md) - Use this to see shopping carts before they become orders.
- [Promotions](./Promotions.md) - Use this for coupons and special deals.
- [Payments](./Payments.md) - Use this to manage payment provider settings and check payment flow.
- [Shipping](./Shipping.md) - Use this to manage shipping prices, methods, and carrier tools.
- [Content](./Content.md) - Use this to change store words, sections, and public page content.
- [Customers](./Customers.md) - Use this to review customer records.
- [Orders](./Orders.md) - Use this every day to process orders.
- [Invoices](./Invoices.md) - Use this to preview and print customer invoices.
- [Reviews](./Reviews.md) - Use this to approve survey and product reviews.
- [Alerts](./Alerts.md) - Use this as the store notice board.
- [Email](./Email.md) - Use this to set up SMTP email and send test emails.
- [Site](./Site.md) - Use this to control public website settings.
- [Store Info](./Store%20Info.md) - Use this to set the store name, address, phone, and email.
- [Taxes](./Taxes.md) - Use this to manage state, county, city, other, VAT, and import tax rules.
- [Users](./Users.md) - Use this to manage admin users.
- [Analytics](./Analytics.md) - Use this to see traffic and store activity.
- [Reports](./Reports.md) - Use this to understand money, products, shipping, and taxes.
