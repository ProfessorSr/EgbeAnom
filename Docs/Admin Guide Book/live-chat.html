Admin Page

Live Chat

Use this to open or close storefront live-chat help and respond to customer requests.

How Customers Use Live Chat

  • Customers select Open live chat in the bottom-right corner of the storefront.
  • They enter their name, email address, and help message.
  • Select Close to collapse the chat panel without leaving the page.
  • A submitted request appears in admin Alerts as a customer contact message.

Open Or Close Live Chat

  • Open Admin, then Site.
  • Turn Live chat help on to show it to customers.
  • Turn Live chat help off to close it and hide it from the storefront.
  • Save Site settings after changing the option.

Daily Use

  • Check Alerts for new live-chat help requests.
  • Use the customer email address in the request to follow up.
  • Close live chat from Site settings when support is unavailable.
