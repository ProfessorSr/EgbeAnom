Handoff Book

Start Here

This book explains the admin area in simple words. Use it when training the owner or checking how to do normal store work.

Main rule: do not ship an order unless the financial status says paid.
OverviewUse this page first. It shows the biggest numbers and points you to the work that needs attention. CatalogUse this to add, edit, and check products. CategoriesUse this to group products so shoppers can find them. InventoryUse this to watch stock counts and print a simple stock table. CartsUse this to see shopping carts before they become orders. PromotionsUse this for coupons and special deals. PaymentsUse this to manage payment provider settings and check payment flow. ShippingUse this to manage shipping prices, methods, and carrier tools. ContentUse this to change store words, sections, and public page content. CustomersUse this to review customer records. OrdersUse this every day to process orders. InvoicesUse this to preview and print customer invoices. ReviewsUse this to approve survey and product reviews. AlertsUse this as the store notice board. EmailUse this to set up SMTP email and send test emails. SiteUse this to control public website settings. Store InfoUse this to set the store name, address, phone, and email. TaxesUse this to manage state, county, city, other, VAT, and import tax rules. UsersUse this to manage admin users. AnalyticsUse this to see traffic and store activity. ReportsUse this to understand money, products, shipping, and taxes.
